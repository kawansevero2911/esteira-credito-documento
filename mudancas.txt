GRUPO 6 — ESTRUTURAÇÃO DE DOCUMENTOS — V1.3.0

ANTES (v1.1.0):
- API FastAPI para operação de crédito genérica.
- Validação JSON Schema, geração PDF, metadados JSON, evento local e testes.

INCREMENTO FINOPS:
- Adaptador GET somente leitura para operação e parcelas.
- Endpoint offline para receber JSONs e gerar demonstrativo financeiro.
- Schema específico e testes com mock.

INCREMENTO CREDCASA:
- Adaptador GET somente leitura para /api/esteira/{id}.
- Endpoint offline para gerar proposta imobiliária a partir do JSON do grupo.
- Schema mínimo, template PDF e testes.

PERSISTÊNCIA:
- Adaptador MongoDB opcional com Docker Compose; arquivos JSON continuam disponíveis como fallback padrão.

JUSTIFICATIVA:
- Isolar contratos de dados diferentes, não modificar os outros grupos, permitir demonstração sem APIs externas e manter rastreabilidade por UUID e evento.

PENDÊNCIAS EXPLÍCITAS:
- Testar integrações ao vivo com IDs reais; ajustar mapeamento CredCasa caso o JSON real difira do exemplo.
- Autenticação, barramento real e contratos jurídicos fora do escopo desta versão acadêmica.
